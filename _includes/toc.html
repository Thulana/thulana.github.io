{% comment %} Table of contents built from the rendered content. The theme ships an `_includes/toc` that uses kramdown's `{:toc}`, but that only works inside a Markdown document — Liquid expands includes in a layout *after* kramdown has already run, so the marker is emitted literally. This version parses the rendered HTML instead, which works from the layout and needs no JS. Relies on `kramdown.auto_ids: true` (set in _config.yml) for heading anchors. {% endcomment %} {% assign toc_parts = content | split: '

' | first | strip_html | strip %} {% if heading_id and heading_text != '' %}
  • {{ heading_text }}
