{% comment %} Module scripts use a root-relative src on purpose, not {{ base_path }}. base_path is absolute and built from site.url. The site is served at the apex domain, so an absolute www URL (or vice versa) makes these a cross-origin request — and ES modules are fetched in CORS mode, unlike classic scripts. GitHub Pages sends no Access-Control-Allow-Origin, so the browser blocks them silently: every animation dies while main.min.js, being a classic script, keeps working. A root-relative path is same-origin on whichever hostname the visitor arrived at. {% endcomment %} {% comment %} Site background.
